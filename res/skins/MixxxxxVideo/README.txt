Mixxxxx Video Skin
==================

LateNight layout with video defaults ON. Reuses LateNight SVG/templates from
res/skins/LateNight/ — this folder only ships skin.xml + style_daylight.qss.

Select in Preferences -> Interface -> Skin -> "Mixxxxx Video".

Color schemes (skin settings gear, or Preferences -> Interface -> Scheme):
  PaleMoon, Classic — same as LateNight (dark)
  Daylight — light panels for outdoor / bright rooms (Mixxxxx-only)

Video COs enabled by default:
  [Skin],show_video_preview
  [Skin],show_video_output
Spinnies/cover art off (deck previews use VideoWidget).

User-folder install (optional):
  mixx-dj-mcp: mixx_skin(operation="create_video_skin")
  copies this skin to %LOCALAPPDATA%\Mixxx\skins\MixxxxxVideo

See docs/SKINS.md for community skin sources.
