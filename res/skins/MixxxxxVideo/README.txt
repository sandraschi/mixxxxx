Mixxxxx Video Skin
===================

This directory is a placeholder. The Mixxxxx Video skin is generated by
patching the LateNight skin at runtime. To enable it:

1. Ensure LateNight is installed (it ships with Mixxx)
2. Use the `mixx_skin` tool in mixx-dj-mcp:
     mixx_skin("create_video_skin")
3. Select "Mixxxxx Video" in Preferences -> Interface -> Skin

The video skin patch:
- Enables show_video_preview and show_video_output by default
- Disables spinny and cover art (replaced by video preview)
- Shows 4 decks, hotcues, microphones, and equalizers
- Adjusts layout for optimal video viewing

To manually patch LateNight for video:
1. Copy res/skins/LateNight/ to res/skins/MixxxxxVideo/
2. Edit skin.xml: set show_video_preview=1, show_video_output=1
3. Optionally disable show_spinnies=0, show_coverart=0
4. Restart Mixxx and select Mixxxxx Video from Preferences
