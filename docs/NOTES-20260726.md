## NDI (Network Device Interface)

**What it is:** Live video (and audio) over LAN. mixxxxx would publish a named
source; OBS, Resolume, vMix, etc. subscribe — no HDMI cable, no window capture.

**What it is not:** A file format, a codec, or a VDJ marketplace feature.

**Status:** Documented only — [`NDI.md`](NDI.md), mixx-dj-mcp Help → NDI tab.

## Beat-locked FX (TODO 25 MVP)

COs per deck (Developer Tools or `--set-control`):

```
[Channel1],video_beat_fx_strobe=1
[Channel1],video_beat_fx_zoom=1
[Channel1],video_beat_fx_strobe_amount=0.8
[Channel1],video_beat_fx_zoom_amount=0.5
[Channel1],video_beat_fx_division=2    # 0=1 beat, 1=2, 2=4, 3=8, 4=16, 5=32
```

Requires analyzed track (beat grid) + video skin with `VideoWidget` (registers COs).
Beat index from `beat_closest` + `bpm` — survives seeks/hotcues (see REVIEW-20260726-FXCHAIN fixes).
